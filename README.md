## Download

| | |
|---|---|
| **Linux** | [WindowWarp-x86_64.AppImage](https://github.com/WindowWarp/windowwarp.github.io/releases/latest/download/WindowWarp-x86_64.AppImage), free. How to install: [windowwarp.github.io/linux.html](https://windowwarp.github.io/linux.html) |
| **Windows** | Microsoft Store, coming soon |
| **Android TV, phone and tablet** | WindowWarp Receiver on Google Play, coming soon |

You need two apps: the computer app on the computer that sends the picture, and WindowWarp Receiver on the device that shows it.
