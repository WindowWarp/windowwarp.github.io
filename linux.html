WindowWarp for Linux

KDE Plasma and GNOME on Wayland, and the Steam Deck in desktop mode. Pick your system.

One file that works almost everywhere: the Steam Deck, Bazzite, Fedora Silverblue, openSUSE and any other distro. Nothing to install.

Download as anAppImage
  1. Download it and put it where you want to keep it, such as your home folder.
  2. Make it executable: right-click › Properties › Permissions › Allow executing. Or run chmod +x on the file.
  3. Double-click to start. The first time, pick the screen to share and allow it.

Updates

WindowWarp shows a line at the top of its window. One click.

Remove

Turn off Start when you sign in, quit from the tray and delete the file.

For Ubuntu 24.04 and newer, Debian 13, Linux Mint 22, Pop!_OS, Zorin OS, elementary OS, KDE neon and other systems based on them. Paste the three lines in a terminal.

$ curl -fsSL https://windowwarp.github.io/linux/windowwarp.asc | sudo gpg --dearmor -o /usr/share/keyrings/windowwarp.gpg $ echo "deb [signed-by=/usr/share/keyrings/windowwarp.gpg arch=amd64] https://windowwarp.github.io/linux/deb stable main" | sudo tee /etc/apt/sources.list.d/windowwarp.list $ sudo apt update && sudo apt install windowwarp
  1. Key: the first line adds our signing key, so your system only accepts packages that really come from us.
  2. Source: the second line adds WindowWarp to your package sources.
  3. Install: then find WindowWarp in your app menu and start it.

Updates

Come with your normal system updates: sudo apt upgrade, or Discover / Software.

Remove

sudo apt remove windowwarp

For Fedora and its spins, Nobara, and Red Hat Enterprise Linux 10, AlmaLinux 10 and Rocky Linux 10.

$ sudo curl -fsSLo /etc/yum.repos.d/windowwarp.repo https://windowwarp.github.io/linux/rpm/windowwarp.repo $ sudo dnf install windowwarp
  1. Source: the first line adds WindowWarp to dnf.
  2. Install: dnf asks once to trust the key. Check that it says WindowWarp Linux packages and answer y.
  3. Find WindowWarp in your app menu and start it.

Updates

Come with sudo dnf upgrade, or Discover / Software.

Remove

sudo dnf remove windowwarp

Then on your TV, phone or tablet

Install WindowWarp Receiver from Google Play, choose Search, pick your computer and click Allow on the computer. After that it connects by itself.

What you need

  • Wayland with KDE Plasma or GNOME, or a Steam Deck
  • An NVIDIA, AMD or Intel graphics card
  • 64-bit, a recent distribution (see the tabs above)
  • Computer and device on the same network

If something is off

The device doesn't find the computerSame network? A firewall should allow TCP 5859 and UDP 5860.
apt says NO_PUBKEY or "not signed"The first line (the key) was skipped. Run it again, then sudo apt update.
AppImage: double-click does nothingThe file is not executable yet. See step 2 under Steam Deck · other.
